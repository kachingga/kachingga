## Integración con Mercado Pago

Objetivo: saldar una deuda desde la app con Mercado Pago, sin tener que copiar datos a mano. Se mantiene la opción de saldar manualmente (v1).

### Enfoques

| | **A. Abrir Mercado Pago con los datos del otro** (recomendado) | B. Cobro con la API de Mercado Pago (Checkout Pro) |
|---|---|---|
| Cómo | Cada uno guarda su **alias/CVU** en su perfil. "Pagar" en una transferencia sugerida copia alias + monto y abre la app de Mercado Pago; se transfiere ahí | Cada uno vincula su cuenta de Mercado Pago (OAuth); la app genera un cobro (link/QR) por el monto exacto |
| Comisiones | **No**: es una transferencia común entre cuentas | **Sí**: Mercado Pago cobra comisión al que recibe (lo trata como una venta). Confirmar valores vigentes |
| Marcar como pagado | Manual: al volver, "Ya pagué" registra el `Settlement` | Automático: webhook de Mercado Pago a la API registra el `Settlement` |
| Complejidad | Baja | Alta (OAuth, webhooks, firma, temas legales si la app es pública) |

**Decisión tentativa: A.** Sin comisiones y simple; se pierde solo la confirmación automática.

### A investigar al arrancar la v2
- Si Mercado Pago permite abrir su app con **destinatario y monto precargados** (deep link / universal link) o solo abrirla y que el usuario pegue el alias.
- Validar alias/CVU al guardarlo.
- Pagos en monedas "mantenidas" (ej. USD): Mercado Pago transfiere en ARS.

### Notas de diseño (solo si se elige B)
- Las credenciales de Mercado Pago viven solo en la API (Railway).
- El webhook es una ruta Hono normal (no tRPC, porque lo llama Mercado Pago) y valida la firma antes de marcar algo como pagado.
